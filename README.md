# CashTrack

A local-first personal finance app for tracking everyday spending, monthly category
budgets, and money lent or borrowed. Everything is stored on the device: there is no
account, no server, and no analytics, so expenses, limits and debts never leave the
phone. CashTrack can track recurring expenses, warn you as you approach a category limit,
and export any month as a PDF or CSV report.

## Stack

- **Expo SDK 57** with **Expo Router** (file-based routing, routes in `src/app/`)
- **React Native 0.86** / React 19, targeting iOS, Android and web
- **TypeScript** in strict mode
- **AsyncStorage** for persistence (expenses, debts and preferences)
- **Reanimated** and **react-native-gesture-handler** for motion
- Local notifications for budget and debt-due alerts, generated by `expo-notifications`
- PDF and CSV export via `expo-print`, `expo-sharing` and `expo-file-system`

## Getting started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `a` / `i` for an Android emulator or iOS
simulator. The app uses `expo-sqlite`, so a development build is required for those
native features:

```bash
npx expo run:ios      # or: npx expo run:android
```

## Scripts

| Command | What it does |
| --- | --- |
| `npx expo start` | Start the dev server |
| `npm run typecheck` | Type-check the project with `tsc --noEmit` |
| `npm run lint` | Lint with `eslint-config-expo` |
| `npm test` | Run the unit tests with the Node test runner |

## Project layout

```
src/app/        screens and routes (Expo Router)
src/components/ reusable UI, including the design-system primitives
src/constants/   theme tokens, categories and country/currency data
src/context/     expense and debt providers
src/storage/     AsyncStorage persistence and row validation
src/utils/       formatting, budgets, recurrence, exports, notifications
tests/           unit tests for the pure logic
```

## Building with EAS

The project is set up for [EAS Build](https://docs.expo.dev/eas/build/introduction/):

```bash
npx eas-cli build --profile development   # internal development build
npx eas-cli build --profile production    # store build
```
